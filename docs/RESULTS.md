# キノコ体は、ランダム配線に勝っているのか

MaleCNS v1.0（2026年9月公開）の実測コネクトームを使って、ショウジョウバエのキノコ体を
**ランダム配線と同じ土俵で測った**記録。

対象は右半球のキノコ体。ALPN 162本 → ケニヨン細胞 2,045個 → MBON 63本。
結合は neuPrint の公開Cypherエンドポイントから取得（無認証で叩ける）。

抽出の健全性チェック: KC 1個あたりのALPN入力は **平均 5.5本**。
「各KCは約6個の糸球体をサンプルする」という文献値と一致するので、部分グラフの切り出しは正しい。

---

## 動機

Dasgupta, Stevens & Navlakha (Science 2017) は、嗅覚回路が
**locality-sensitive hashing（LSH）** として振る舞うことを示した。
少数の糸球体から数千のKCへスパースに展開し、勝者総取りで絞る。
ただしそこでの「ランダムな展開」は**解剖学的な仮定**だった。

実測行列が手に入ったので、仮定を実物に差し替えて測れる。問いは2つ。

1. 実際の配線は、ランダム配線より良いハッシュか
2. 1区画あたり、何件の記憶を保持できるか

---

## 実験1 — ハッシュ性能（`experiments/exp1_hash.py`）

入力の近傍構造が、KCコードの近傍構造にどれだけ保存されるか。mAP@50 で評価。

### 途中で見つけた自分の設定ミス

最初の実装には欠陥が3つあり、どれも**ランダム行列に有利**に働いていた。

- **非嗅覚KCの混入**。ALPN入力が0のKCが128個あった。内訳は `KCg-d` 88個と `KCab-p` 39個。
  KCg-d は視覚入力を受ける型として知られる。匂いに反応しようのない細胞に
  勝者総取りの枠を食わせていたので除外した。
- **入力の実効次元の水増し**。162本のPNを独立チャンネルとして乱数を振っていた。
  実際は糸球体に対するパターンで、同じ糸球体のPN（平均2.5本）は
  ほぼ同じ信号を運ぶ。糸球体レベルで生成してPNに配る方式に直した。
- **読まない入力での採点**（2回目の見直しで発見）。糸球体モデルでも、
  多糸球体PN 25本を1本ずつ独立したチャンネルとして扱い、温度・湿度の VP 糸球体にも匂いと同じ統計で信号を入れていた。
  89チャンネルのうち37がこれにあたるが、多糸球体PNがKCに出す結合は全体の **1.3%** しかない。
  正解（入力空間での近さ）にはこれらの次元も入るので、キノコ体が「読まないことにしている」入力を
  読めないことで減点されていた。匂いを運ぶ52糸球体だけに入力する `olfactory` モデルを加え、主な比較はこちらで行う。

3つの入力モデルをすべて併記してある。

![ハッシュ性能](../figures/fig1.svg)

### 結果（5試行の平均±標準偏差）

| 条件 | olfactory | real比 | glomerular（旧） | real比 |
|---|---|---|---|---|
| `real` 実測のシナプス数 | 0.3931 ± 0.0073 | — | 0.2934 ± 0.0072 | — |
| `binary_real` 配置はそのまま、重みを全部1に | 0.5195 ± 0.0068 | **+32.2%** | 0.3832 ± 0.0083 | +30.6% |
| `degree_swap` 次数列を完全保存して張り替え | 0.3863 ± 0.0077 | −1.7% | 0.2894 ± 0.0056 | −1.3% |
| `pn_degree_kept` PN側の次数と重みだけ保存 | 0.3880 ± 0.0082 | −1.3% | 0.2911 ± 0.0070 | −0.8% |
| `kc_degree_kept` KCの入次数だけ保存 | 0.6699 ± 0.0048 | +70.4% | 0.6265 ± 0.0072 | +113.5% |
| `uniform` 同じ本数を一様ランダム配置 | 0.6583 ± 0.0033 | +67.5% | 0.6214 ± 0.0083 | +111.8% |
| `gaussian_lsh` 密なランダム射影 | 0.7123 ± 0.0025 | +81.2% | 0.6381 ± 0.0078 | +117.5% |

PN独立モデル（`pn_independent`）でも同じ順序が出る（`results/exp1_hash.json`）。

### 読み取れること

**① 配線の「特異性」はない。** `real` と `degree_swap` が誤差内で一致する。
次数列を保ったまま辺を全部張り替えても性能が変わらない。
**どの糸球体がどのKCに繋がるかという個別の対応関係には、情報がない。**
Dasgupta らのランダム仮定は、辺の配置レベルでは実測データで支持された。

**② ただし実物は一様ランダムに負ける。そして差は丸ごとPN側で説明できる。**
対照を左右対称に組んである。KC側（1個のKCが何本の入力を受けるか）だけ保った `kc_degree_kept` は
`uniform` と一致し、PN側（1本の入力が何個のKCに、どれだけ強く届くか）だけ保った `pn_degree_kept` は
`real` と一致する。偏っているのはPN側。

差の大きさは採点しだいで、旧来の `glomerular` では +112%、`olfactory` では +67%。
**当初「2倍以上負ける」と書いていたのは、差の4割ほどが採点の産物だった。** 残りの +67% は本物。

**③ 偏りの中身。** 糸球体ごとにKCへの結合数を数えると:

![糸球体ごとの結合数](../figures/fig2.svg)

| 上位 | 結合数 | 文献上の役割 |
|---|---|---|
| DC1 | 473 | 匂い |
| DP1m | 446 | 酢酸 — 発酵果実 |
| VM5d | 389 | 匂い |
| DM1 | 387 | 果実のエステル類 |
| DM6 | 385 | 匂い |
| DM2 | 371 | 果実のエステル類 |
| DA1 | 322 | cVAフェロモン |
| DM4 | 302 | 酸・食物 |

| 下位 | 結合数 | 何か |
|---|---|---|
| VP1m+VP2 | 14 | **温度・湿度** |
| VP4 | 9 | **温度・湿度** |
| VP1m+ | 8 | **温度・湿度** |
| VP2+ | 5 | **温度・湿度** |
| VP1l+VP3 | 3 | **温度・湿度** |

上位5糸球体で全結合の **18.4%**（一様なら7.7%）。ジニ係数 0.378。

役割ごとの中央値は、食物 290（8糸球体）、フェロモン 148.5（4）、その他の匂い 194.5（40）、温度・湿度 18（12）。

- **温度・湿度をほぼ読まない**のは明白。
- **「食物とフェロモンに集中させている」とは言えない。** 食物＋フェロモン対その他の匂いで
  片側置換検定 p = 0.063。フェロモン系はむしろ中央値以下。
  上位の表だけを見るとそう読みたくなるが、DC1・VM5d・DM6 のような「その他」も同じくらい多い。
  以前の版はこの点を言い過ぎていた。

一般的な近傍検索で一様ランダムに負けるのは、読む入力の配分の結果。
その配分のうち、はっきり意味が読み取れるのは「温度や湿度は覚える対象にしない」という部分。

**④ シナプス数は重みとして悪い。** `binary_real` が `real` に30〜36%勝つ。
本数を重みとして使うと性能が落ちる。
実際の結合強度が本数よりも均一なら、回路は解剖が示すより良いハッシュになる。
これは検証可能な予測になっている。

## 実験2・3 — 記憶容量（`experiments/exp2_capacity.py`, `experiments/exp3_compartments.py`）

実測の KC→MBON 行列上で、ドーパミン依存のLTD（結合を弱める学習）を回す。
学習済みの匂いと未学習の匂いを、MBONへの入力の大小で分離できるかを AUC で測る。

### 結果

![記憶件数と分離性能](../figures/fig3.svg)

| k（記憶件数） | real | degree_swap | uniform | 解析近似 (1−f)^k |
|---|---|---|---|---|
| 5 | 0.984 | 0.992 | 0.998 | 0.774 |
| 12 | 0.971 | 0.985 | 0.988 | 0.540 |
| 20 | 0.956 | 0.970 | 0.967 | 0.358 |
| 30 | 0.915 | 0.940 | 0.928 | 0.215 |
| 50 | 0.849 | 0.868 | 0.832 | 0.077 |

**容量（AUC≥0.95）: real k=20 / degree_swap k=25 / uniform k=20。**

### KC→MBON 側の特異性は、小さいが逆向きに出る

実験2の標準偏差（0.04〜0.07）は、試行ごとにランダムに選ぶ区画の大きさの違いがほとんどを占める。
これだけ見ると3条件は区別できないが、**区画ごとに対応をとると差が出る**（実験3で51区画すべてを比較）:

| 張り替え − 実測（AUC, k=20） | 95% 信頼区間 | 張り替えのほうが高い区画 |
|---|---|---|
| **+0.014** | +0.008 〜 +0.022 | 51区画中37 |

実測の配線のほうが、わずかに**悪い**。実物の区画は特定の葉のKCしか読まない
（たとえば MBON12 γ2α'1 は γ と α'/β' のKCだけ）。張り替えはこの制約を壊し、
どの区画も全種類のKCを読むようになる。合成の匂いはどのKC型も同じように光らせるので、
混ぜたほうが少しだけ分離しやすくなる、というのが自然な解釈。

`uniform` は区画ごとの大きさ（読むKCの数）まで均してしまうので、区画単位の比較には向かない。

### 解析近似は悲観的すぎた

「f=5% なら13.5件で信号が半減する」という見積もりは、margin の減衰としては正しい。
ただし**識別できなくなる件数はそれより大きい**。
k=12 で margin は0.54まで落ちているのに AUC は0.971 ある。
読み出しが絶対閾値ではなく順序比較で、分散も同時に縮むため。

### 容量は単一の数字ではなく、区画ごとのポートフォリオ

![区画のサイズと容量](../figures/fig4.svg)

区画（MBON）が読むKCの数は **123個から1,713個** まで13倍以上開いている。
そして容量はそれに追随する。**相関 +0.857（log KC入力数 vs AUC@k=20）。**

| KC入力数 | 容量(AUC≥0.9) | 区画 |
|---|---|---|
| 1,713 | ≥50 | **MBON11 (γ1pedc>α/β)** |
| 1,513 | ≥50 | MBON22 (calyx) |
| 1,077 | ≥50 | MBON02 (β2β'2a) |
| … | | |
| 161 | <5 | MBON19 (α2p3p) |
| 123 | 5 | MBON10 (β'1) |

**MBON11（γ1pedc>α/β）が最大**というのが効いている。
これは嫌悪条件づけで最もよく研究されているMBONで、
**一番学習に使われる区画が、一番容量が大きい**。

## 実験4 — 実在の匂いで（`experiments/exp4_real_odors.py`）

実験1〜3の匂いは合成データだった。DoOR 2.0 の実測応答から組み立てた **67物質**（47糸球体）を
同じ対照に通す。デモと同じ匂いなので、[DEMO.md](DEMO.md) に書いたデモの数字もすべてここから出ている。

### A. 似た匂いが、似たコードになるか

67物質では mAP@50 は意味をなさないので、全2,211ペアについて
「入力（受容体レベル）の類似度」と「KCコードの重なり」の順位相関をとる。
ランダムな対照はそれぞれ20本引き、実測がその分布のどこにいるかを見る。

![実在の匂いでの類似度保存](../figures/fig5.svg)

| 条件 | 順位相関 |
|---|---|
| `real` | 0.841 |
| `binary_real` | 0.886 |
| `degree_swap` | 0.840 ± 0.012 |
| `pn_degree_kept` | 0.838 ± 0.012 |
| `kc_degree_kept` | 0.924 ± 0.010 |
| `uniform` | 0.925 ± 0.010 |

実測は、次数保存で張り替えた20本の **50パーセンタイル**。実験1の①②④が、実在の匂いでもそのまま再現する。

### B. 1つ罰すると、何を避けるようになるか

MBON11 の区画で、67物質を1つずつ罰して、残り66物質の入力の低下を調べた。

- 回避の強さと受容体レベルの類似度の相関（67物質の平均）: **r = 0.819**
  （張り替え 0.809、一様ランダム 0.893）
- 最も避けるようになった上位5件に、罰した物質と同じ化学クラスが入る率: **偶然の3.89倍**。
  クラスのラベルを入れ替えた置換検定（2,000回）で p = 0.0005
- 張り替えた配線では、同じ匂いで光るKCが実測と **8.1%** しか重ならない（偶然なら5.0%）。
  それでも回避のプロファイルは実測と **r = 0.934** で一致する

最後の点が、「個々の配線に情報がない」の一番具体的な形。KCのレベルでは別物のコードなのに、
行動のレベルでは同じ匂いを混同する。

### C. 何件で崩れるか

デモの判定（学習した匂いの入力が、未学習の匂いの下位10%より小さければ「区別できている」）を、
ランダムな学習順500通りで平均した。

| 区画 | KC | 5 | 10 | 15 | 20 | 30 | 45 |
|---|---|---|---|---|---|---|---|
| MBON11 γ1pedc>α/β（罰） | 1,713 | 1.00 | 0.96 | 0.87 | 0.75 | 0.57 | 0.43 |
| MBON02 β2β'2a（報酬） | 1,077 | 0.99 | 0.91 | 0.81 | 0.66 | 0.46 | 0.41 |
| MBON12 γ2α'1（罰） | 979 | 1.00 | 0.91 | 0.78 | 0.61 | 0.40 | 0.31 |
| MBON01 γ5β'2a（報酬） | 938 | 1.00 | 0.91 | 0.80 | 0.65 | 0.41 | 0.30 |
| MBON07 α1（報酬） | 914 | 0.96 | 0.84 | 0.76 | 0.61 | 0.44 | 0.40 |
| MBON19 α2p3p（罰） | 161 | 0.35 | 0.19 | 0.16 | 0.14 | 0.12 | 0.16 |

大きい区画は10件あたりから崩れ始め、実験2の容量（k=20）と合う。
161個しか読まない MBON19 は、5件でもすでに持たない。

## 実験5 — ハエのおつかい（`experiments/exp5_errand.js`）

実験1〜4は「コードがどうなるか」までだった。これは行動まで通す。
商品の匂いを1回嗅がせて砂糖をあげたハエを店に放し、何を持ってくるかを数える。
シミュレーションは `web/errand-core.js` で、`/errand` のページと同じコードが動く。

- **本物**: 成分の受容体応答（DoOR）、PN→KC の配線（MaleCNS）、1回の対提示で覚える学習則、罰と報酬の区画
- **仮定**: 商品は代表成分1〜3種の等量混合。空調の風で匂いが風下へ筋（プルーム）になって伸び、重なると線形に混ざる。
  ハエは欲しい匂いを感じたら風上へ進み、左右の触角で濃い側へ寄り、見失ったら探し回る
  （歩くハエの定位行動、Álvarez-Salvado et al. 2018 を最小限に写したもの）。棚の前では、隣から流れてくる匂いではなく
  その商品そのものの匂いで判断し、欲しさが 1.4 を超えていれば手に取る
- **入っていない**: 生まれつきの好み（側角）。何も教えないハエは何も買わない

「欲しさ」は、ある地点の空気をキノコ体に通したときの出力ニューロンの変化から計算する。
報酬の区画（出口は「避けろ」）の入力が落ちれば正、罰の区画（出口は「近づけ」）の入力が落ちれば負。

### A. 何を持ってくるか

14品それぞれを頼み、棚の並び10通り × 20匹。

![おつかいの結果](../figures/fig6.svg)

頼んだ品を持ってくるのは **74%**（95% CI 72〜75%）。棚をでたらめに選べば7%。何も買わずに帰ってくるのは平均10%。

| 頼んだ品 | 正解 | 取り違え | 何も買わない |
|---|---:|---|---:|
| パイナップル | 97% | — | 3% |
| 湿布 | 94% | — | 7% |
| 生ゴミ | 94% | — | 6% |
| お酢 | 92% | — | 9% |
| バラ | 89% | — | 11% |
| リンゴ | 87% | — | 14% |
| チーズ | 86% | — | 14% |
| キノコ | 80% | — | 20% |
| ハチミツ | 74% | — | 27% |
| ワイン | 63% | 杏仁豆腐 31% | 6% |
| バナナ | 51% | 日本酒 43% | 7% |
| バター | 50% | お酢 50% | 1% |
| 日本酒 | 43% | バナナ 38% | 20% |
| 杏仁豆腐 | 36% | ワイン 60% | 4% |

取り違えは、香りの成分がかぶる3組にだけ出る。バナナと日本酒はどちらも酢酸イソペンチルを含む。
それ以外の品で失敗するのは、頼んだ品の匂いの筋に出会えずに手ぶらで帰ってくる場合だけ。
全182組で、取り違えの頻度は学習後の「欲しさ」と **r = 0.41** で相関する（取り違えがほとんど0の組が多いので、相関は控えめに出る）。

棚の前での判断は、その商品そのものの匂いで行う。最初の版は棚の前の空気（隣の棚から流れてくる匂いが混ざったもの）で判断していて、
頼んだ品の目の前にいながら、混ざった匂いで欲しさが薄まって見送るハエが多かった（正答62%、失敗の多くが手ぶら）。

### B. 実物の配線は、おつかいに効いているか

同じ棚・同じハエで、張り替えた脳と比べた（棚の並び3通り × 20匹 × 14品、脳1個ずつ）。

| 脳 | 正答率 | 実測より下だった数 | 順位検定 |
|---|---|---|---|
| 実測の配線 | 73% | — | — |
| 次数保存で張替（19個） | 66 ± 4% | 19個中19 | p = 0.05 |
| 一様ランダム（19個） | 58 ± 5% | 19個中19 | p = 0.05 |

順位検定は「実測の配線も張り替えた脳の1つにすぎない」とした場合に、実測が今の順位以上になる確率。
どちらの対照に対しても実測は20個中1位で、この試行数で出せる最小の p になる。

これは実験1・4と食い違って見える。
- 実験1・4（似た匂いを似たコードにするか）では、実測と次数保存の張り替えは区別できず、一様ランダムのほうが上だった（0.92 対 0.84）
- おつかいでは、実測が両方に勝つ

**似たものを似たまま保つことは、似た商品を見分ける課題ではむしろ不利に働く**と読める。
汎用のハッシュとしての劣化（実験1の②）が、この品ぞろえの見分けにはプラスに出ている。
次数保存の張り替えにも勝つので、一本一本の配線にも、この14品の見分けに効く何かがあることになる。
ただし品ぞろえは14品で、この差がどの匂いの組み合わせでも出るかは分からない。

### C. 取り違える相手を罰すれば直るか

頼んだ品に砂糖、いつも取り違える品に罰を与える（2つの匂いを対比させて教える方法。本物のハエでは区別が鋭くなる、Barth et al. 2014）。
取り違えが5%以上あった5品で試した。

| 頼んだ品（罰した品） | 正解 | 取り違え | 何も買わない | 欲しさ（頼んだ品 / 罰した品） |
|---|---|---|---|---|
| バター（お酢） | 50% → **92%** | 50% → 0% | 8% | 2.55 / 1.44 → 1.47 / −1.11 |
| ワイン（杏仁豆腐） | 63% → **81%** | 31% → 0% | 20% | 2.55 / 1.57 → 1.40 / −0.98 |
| バナナ（日本酒） | 51% → 0% | 43% → 0% | 100% | 2.55 / 1.43 → 0.57 / −1.12 |
| 日本酒（バナナ） | 43% → 0% | 38% → 0% | 100% | 2.55 / 1.46 → 1.07 / −1.09 |
| 杏仁豆腐（ワイン） | 36% → 0% | 60% → 0% | 100% | 2.55 / 1.55 → 1.20 / −1.00 |

取り違えはどの組でも0になり、2つの欲しさの差もすべて広がった。区別そのものは鋭くなっている。
バターとワインでは、狙いどおり正答が大きく上がる。

ところが、**よく似た組ほど、頼んだ品の欲しさまで一緒に下がる**。バナナと日本酒はケニヨン細胞の大半を共有しているので、
日本酒を罰すると、バナナを読む細胞の多くも「近づけ」の出口で弱められる。
バナナの欲しさは 0.57 まで落ち、匂いをたどる基準（0.9）も手に取る基準（1.4）も下回る。結果、ハエは何も買ってこなくなる。

本物のハエは、よく似た匂いでも対比させて教えれば見分けられるようになる。このモデルでそれができないのは、
学習がキノコ体の出口の結合を弱めるだけで、手に取るかどうかを絶対的な基準で決めているから。
2つを並べて比べさせる課題（T字迷路）なら、差が広がった分だけ成績は上がるはず。
どちらの仕組みが本物に近いかは、似た匂いの対比学習で「どちらも選ばない」ハエが増えるかを測れば区別できる。

---

## まとめ

1. **辺の張り方には情報がない。** PN→KC は、合成の匂いでも実在の匂いでも、
   次数を保ったランダム張り替えと区別できない。ランダム展開という仮定は実測で支持された。
2. **PN側の次数分布には情報がある。** それが一般的な検索性能を下げている（一様ランダム比 −40%）。
   はっきり読める中身は、温度と湿度を読まないこと。食物やフェロモンへの集中は支持されなかった。
3. **KC→MBON 側では、実測のほうがわずかに悪い。** 区画が特定の葉のKCしか読まないことの代償と読める。
4. **容量は区画ごとに10倍違う。** 平均20〜30件という数字より、
   大きい区画（50件以上）と小さい区画（5件未満）の分業として見るほうが正しい。
5. **行動まで通すと、実物の配線が効いてくる。** 1回嗅がせた商品を店から取ってくるおつかいで、
   実物は73%、次数保存の張り替えは66%、一様ランダムは58%（どちらも20個中1位、p = 0.05）。
   似た匂いを似たコードにする成績では、実物は張り替えと同じ、一様ランダムより下だったので、見分ける課題では向きが逆になる。

## 限界

- 実在の匂いは67物質・47糸球体（MaleCNS 側の64糸球体のうち）。DoOR の測定がある受容体に限られ、
  物質の選び方も研究者の関心（果実・発酵臭が多い）に偏っている。
- 片半球のみ。左右で結果が変わるかは未確認。
- 学習則は決定論的なLTDに単純化してある。
  実際は増強（LTP）、忘却、区画ごとの時定数差がある。
- 糸球体の役割（DP1m=酢酸、VP=温度・湿度 など）と区画の価値（罰・報酬）は文献知識であって、
  このデータセットから導いたものではない。結果の分類と表示に使うほか、VP＝温度・湿度だけは
  実験1の `olfactory` モデルで入力チャンネルを選ぶのに使っている（配線には一切触れない）。
- 実験4Bの「化学クラス」は DoOR の分類そのまま。1物質しかないクラスや "other" は集計から外した。
- シナプス数を重みの代理としている。この仮定の弱さ自体が④の結果。
- 実験5の行動（歩き方、匂いの広がり、手に取る基準）は仮定。基準の値（0.9 と 1.4）を変えると正答率は動く
  （少数の試行での概算で、1.3 なら正答69%・何も買わない5%、1.8 なら正答85%・何も買わない15%で取り違えは消える。
  基準を上げるほど取り違えは減り、手ぶらで帰るハエが増える）。配線どうしの比較は同じ値で行っている。

## 再現手順

```bash
uv run scripts/fetch_connectome.py
uv run scripts/fetch_odors.py          # 実験4のみ
uv run experiments/exp1_hash.py
uv run experiments/exp2_capacity.py
uv run experiments/exp3_compartments.py
uv run experiments/exp4_real_odors.py
uv run scripts/build_errand.py         # 実験5の店と、張り替えた配線
node experiments/exp5_errand.js        # 10分ほどかかる
uv run pytest                          # flymb の性質テスト
node --test "web/*.test.js"            # おつかいのシミュレーションなど
```

結果は `results/*.json` に出る。乱数シードは固定。図は `uv run scripts/make_figures.py` で `figures/*.svg` に。

**再現の精度について。** 同一環境なら完全に同じ値が出るが、環境をまたぐとビット単位では一致しない。
同じ numpy 2.5.3 でも、システム Python と `uv sync` で作った `.venv` とで
**平均値が最大 0.016% ずれた**（行列積の畳み込み順序の違いによるもの）。

このずれは、比較している効果量より2桁以上小さい:

| | 大きさ | ずれとの比 |
|---|---|---|
| 環境差によるずれ | 0.016% | — |
| real vs degree_swap（＝「差がない」という結論） | 1.7% | 100倍 |
| real vs uniform（＝主要な発見、olfactory） | 67% | 4,200倍 |

つまり結論はどれも影響を受けないが、**「バイト単位で再現する」とは言えない**。
言えるのは小数4桁程度までの一致。
