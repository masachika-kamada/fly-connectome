# サイトの4ページ

サイトの4ページの中身。公開版（GitHub Pages）でも `node web/serve.js`（`http://localhost:5173`）でも、同じ名前で開ける。
ここに出てくる数字は、1章が実験5（`experiments/exp5_errand.js`）、2章が実験4（`experiments/exp4_real_odors.py`）の計算結果。

| ページ | 元になるファイル | 中身 |
|---|---|---|
| `index.html`（トップ） | `web/errand.template.html` → `dist/errand.html` | ハエのおつかい |
| `brain.html` | `web/trainer.template.html` → `dist/trainer.html` | 脳の中を見る（匂いを覚えさせて、キノコ体の中を見る） |
| `explainer.html` | `web/artifact.html` | 解説アニメーション |
| `figures.html` | `web/figures.html` | 実験結果の図6枚 |

`uv run scripts/build_pages.py` が `dist/` を作り、公開用の `site/` をこの名前で組み立てる。
リンクはすべて相対パスなので、`site/` はどこに置いても（GitHub Pages の `/fly-connectome/` の下でも）そのまま動く。
手元のサーバーは以前の `/explainer` などのURLでも開ける。

## 1. ハエのおつかい（トップ）

```
商品の匂い ──▶ キノコ体 ──▶ 「欲しさ」 ──▶ 風上へ歩く ──▶ 手に取る
 代表成分      実測の配線     出力ニューロン    ハエの定位行動     欲しさが基準を超えたら
```

「何を買ってきてもらう？」で商品を選ぶと、その匂いを砂糖と一緒に一度嗅がせる（報酬の区画にドーパミン）。
「10匹おつかいに出す」で店に放すと、ハエは店内を歩いて何かを持ってくる。
14の商品それぞれが、よく知られた香りの成分を出している（バナナなら酢酸イソペンチル、日本酒の吟醸香もやはり酢酸イソペンチル）。

### 何が本物で、何が仮定か

| | |
|---|---|
| **本物** | 成分に対する受容体の反応（DoOR 2.0）、糸球体からケニヨン細胞への配線（MaleCNS v1.0）、1回で覚える学習則、罰と報酬の区画の区別 |
| **仮定** | 商品の香りを代表成分1〜3種の等量混合で近似。店の奥の空調から入口へ風が流れ、匂いは風下へ筋（プルーム）になって伸び、重なったところは足し合わさって混ざる |
| **仮定（行動）** | 欲しい匂いを感じたら風上へ進み、左右の触角で匂いの強い側へ寄り、見失ったら左右を探す。歩くハエで知られている行動（Álvarez-Salvado et al. 2018）を最小限に写したもの |
| **入っていないもの** | 生まれつきの好み（側角）。何も教えないハエは、どの商品にも興味を示さない |

「欲しさ」は、その地点の空気をキノコ体に通したときの出力ニューロンの変化から計算する。
報酬の区画の出口（「避けろ」）が弱まれば正、罰の区画の出口（「近づけ」）が弱まれば負。
1回砂糖をあげた商品そのものは 2.55（報酬の区画3つ × 0.85）になる。
ハエは欲しさが 0.9 を超える空気をたどる。棚の前では、隣の棚から流れてくる匂いが混ざった空気ではなく、
その商品そのものの匂いで判断し、欲しさが 1.4 を超えていれば手に取る（近づけば、商品自体の匂いと味が勝つため）。

何も買わずに帰ってきたハエには、理由が表示される。「頼んだ品をもう欲しがっていない」「棚まで行って見送った」
「欲しい匂いに一度も出会えなかった」「匂いをたどったが棚にたどり着けなかった」のどれか。
頼んだ品の欲しさが基準を下回っているときは、放す前から欲しさの表の下に警告が出る。

### 何を持ってくるか

頼んだ品を持ってくるのは平均74%（偶然なら7%）。取り違えは、香りの成分がかぶる3組にだけ出る。

| 頼んだ品 | 正解 | 取り違え |
|---|---:|---|
| 🍍 パイナップル | 97% | — |
| 🩹 湿布 | 94% | — |
| 🍷 ワイン | 63% | 🍮 杏仁豆腐 31% |
| 🍌 バナナ | 51% | 🍶 日本酒 43% |
| 🧈 バター | 50% | 🫙 お酢 50% |
| 🍶 日本酒 | 43% | 🍌 バナナ 38% |
| 🍮 杏仁豆腐 | 36% | 🍷 ワイン 60% |

それ以外の品での失敗は、頼んだ品の匂いの筋に出会えずに手ぶらで帰ってくる場合だけ（平均10%）。

全14品の表は `results/exp5_errand.json` と図6。

ページでは、店内に「ハエが行きたい空気」を緑で重ねて表示できる。棚の並びを変えると、同じハエでも結果が変わる
（匂いの筋が入口のどこを通るかで、先に出会う商品が変わるため）。

### 「間違いを直してみる」と

いつも取り違える品に罰を与えると、取り違えは消える。うまくいく組もある。
バターを頼んで「お酢は買わないで」と教えると、正答は 50% から 92% に上がる。ワインと杏仁豆腐でも 63% → 81%。

ただし、よく似た組ほど頼んだ品の「欲しさ」まで一緒に下がる。
バナナを頼んで「日本酒は買わないで」と教えると、欲しさの表でバナナが 2.55 から 0.57 に落ち、ハエは何も買ってこなくなる。
ページでは、このとき放す前から欲しさの表の下に警告が出る。

### 配線を張り替えると

「脳を取り替えて比べる」で「シャッフル」「でたらめ」に替えると、同じおつかいでも成績が下がる（実験5では 73% → 66% / 58%）。
「脳の中を見る」（2章）では張り替えても振る舞いがほとんど変わらなかったのと対照的で、理由は RESULTS.md の実験5 B に書いた。

## 2. 脳の中を見る

```
化学物質 ──▶ 受容体 ──▶ 糸球体 ──▶ ALPN ──▶ ケニヨン細胞 ──▶ MBON
         DoOR 2.0 の実測応答       MaleCNS v1.0 の実測配線
```

匂いは **DoOR 2.0 の実測応答から、糸球体の段で入れる**。同じ糸球体の投射ニューロンには同じ信号が届くので、
本物の鼻が出せる入力だけを使っている（投射ニューロンに1本ずつ別の値を入れる方法との違いは、解説アニメーションのG章）。

物質をクリックすると、選んだ区画にドーパミンが届き、その匂いが罰（区画によっては報酬）と結びつく。見えるもの:

### 似た匂いにも同じ反応をするようになる

MBON11 の区画で `ethyl acetate` を罰すると、入力の低下は上から —

| 低下 | 物質 | クラス |
|---:|---|---|
| 63.8% | methyl acetate | エステル |
| 36.7% | ethyl propionate | エステル |
| 33.4% | acetone | ケトン |
| 32.9% | 2-butanone | ケトン |
| 31.7% | ethyl butyrate | エステル |
| 31.6% | propyl acetate | エステル |
| … | | |
| 1.6% | linalool | テルペン |
| 0.3% | ethyl benzoate | 芳香族 |

エステル類と、小さなケトン類が上位に来る。構造の遠い芳香族・テルペンはほぼ無傷。
1例だけでは選び方しだいなので、**67物質すべてを1つずつ罰して**集計した:

- 避けるようになった上位5件に、罰した物質と同じ化学クラスが入る率は **偶然の3.9倍**（クラスを入れ替える置換検定で p < 0.001）
- 回避の強さは、受容体レベルでの類似度と **r = 0.82** で相関する。化学クラスはその近似にすぎない

### なぜそうなるかも出る

右のリストの行をクリックすると、2つの匂いのスパースコードが重ねて表示され、その場で計算が閉じる。

| クリックした匂い | 区画が読む細胞 | 弱められた | シナプス比 | 式 | 低下 |
|---|---|---|---|---|---|
| methyl acetate | 88 | 62（70%） | 75.1% | 0.85 × 75.1% | **63.8%** |
| ethyl benzoate | 95 | 1（1%） | 0.4% | 0.85 × 0.4% | **0.3%** |

避けるかどうかは、**罰を与えた匂いとケニヨン細胞をどれだけ共有しているか**だけで決まる。
影響ゼロの匂いもリストに残してあるのは、それが仕組みの証拠だから。
（複数の匂いを覚えさせて、同じ細胞が2回以上弱められると、低下は単純な積より大きくなる。ページはそのとき式の代わりに理由を出す。）

### 配線を入れ替えられる

「使う脳」で「シャッフル」を選ぶと、各PNが結ぶKCの数と重みを保ったまま相手を一本残らず入れ替えた配線に切り替わる。
同じ匂いで光るKCは実測と約8%しか重ならない（偶然なら5%）のに、何を避けるかは実測と **r = 0.93** で一致する。
実験1の結論（個々の配線には情報がない）を、手で確かめられる。
「でたらめ」は、どの入力が何個のKCに届くかという偏りまで消した配線（実験の対照名では uniform）。

### 記憶が飽和して崩れる

覚えた匂いのうち、まだ区別できているものの割合（ランダムな順番500通りの平均）:

| 覚えた数 | 5 | 10 | 15 | 20 | 30 | 45 |
|---|---|---|---|---|---|---|
| MBON11（1,713 KC） | 100% | 96% | 87% | 75% | 57% | 43% |
| MBON19（161 KC） | 35% | 19% | 16% | 14% | 12% | 16% |

学習が「弱める」方向にしか働かないので、書ける余地が尽きる。
大きい区画の崩れ始めは10〜20件で、実験2の測定値（AUC≥0.95 で k=20）と合う。小さい区画は最初から持たない。
「区別できている」の判定は、学習した匂いの入力が未学習の匂いの下位10%より小さいこと。

### 区画

6つから選べる。罰の区画（MBON11 γ1pedc>α/β、MBON12 γ2α'1、小さい MBON19 α2p3p）と、
報酬の区画（MBON02 β2β'2a、MBON01 γ5β'2a、MBON07 α1）。学習則はどれも同じ引き算で、
罰の区画の出口は「近づけ」、報酬の区画の出口は「避けろ」を出すので、結果が逆向きになる（Aso et al. 2014）。
定義は `flymb/capacity.py` の `DEMO_COMPARTMENTS`。

## 3. 解説アニメーション

3分20秒・8章。脳の地図 → 配線図の作り方 → キノコ体 → 学習の仕組み →
話題になったデモ（DoomFly）の検証 → 入力をどこから入れるか → このサイトで実測したこと。
アニメーションの下に、各章の数字と根拠をまとめてある。

H章の数字は `results/*.json` から手で写している。実験を回し直して値が変わったら、`web/artifact.html` の `sH` も直す。

一度ブラウザ内蔵の音声合成で読み上げる機能を付けていたが、品質が低く全体の足を引っ張るので削除した。
声を足すなら、生成した音声ファイルを同梱する以外にない。
